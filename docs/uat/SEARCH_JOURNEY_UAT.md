# PilgrimCompare search journey: user test (one page)

**For:** 4 or 5 people who have done Umrah. **Time:** about 20 minutes each, on their own phone.
**Rules for the observer:** do not help, hint or explain. If the tester asks a question, answer only "What would you do if I were not here?" Note where they hesitate.

Before each session, open the site on the tester's phone at the home page. They have not used PilgrimCompare before.

## Scenarios (give each one as written, one at a time)

| # | Read this to the tester | What a pass looks like | Notes on confusion |
|---|---|---|---|
| 1 | "You are a family of five from Birmingham. You want to go in December and spend about £1,500 each. Find packages that suit you." | Finds packages departing from Birmingham in December. Can tell which ones are within budget, and understands why any others are shown ("Differs from your search"). | |
| 2 | "You are travelling alone from London and want the shortest trip. Find it." | Uses London (any airport) and sorts or scans by nights. Picks the package with the fewest nights. | |
| 3 | "You are a couple. What matters most is being close to the Haram. Find the closest hotel." | Uses distance (filter or sort) and can say how far the Makkah hotel is. | |
| 4 | "Pick two packages you like and compare them side by side." | Selects two, opens the comparison and reads the differences, including dates and what is included. | |
| 5 | "One package says some details are 'Not provided'. What do you think that means, and what would you do?" | Understands the operator did not give that detail and that they should ask the operator. | |
| 6 | "Who sets the price you see, and when was it last updated?" | Reads the line under the price ("As stated by … updated …"). | |
| 7 | "Send an enquiry about the package you like best." | Completes the short form, sees a reference code and understands they pay the operator directly. | |
| 8 | "Search for something that does not exist, for example departing in June from Manchester. What does the page tell you?" | Sees the "No packages currently match" message and can clear the search or contact PilgrimCompare. | |
| 9 | "Share the results you are looking at with a friend. Open the link again." | The same results appear after opening the link or reloading. | |
| 10 | "Is PilgrimCompare taking your money or your booking?" | Says no: they pay the operator directly, and the operator confirms the booking. | |
